# Task 2: Intelligent FAQ Chatbot using NLP & Cosine Similarity

An interactive AI-powered FAQ Chatbot built with **Python**, **NLTK**, **Scikit-learn**, and **Streamlit**. This project preprocesses user queries, computes TF-IDF vector embeddings, and uses Cosine Similarity to accurately retrieve the most relevant answer from a structured FAQ dataset.

---

## 🌟 Features
* **Text Preprocessing:** Tokenization, lowercasing, punctuation, and stop-words filtering using NLTK.
* **Semantic Vectorization:** TF-IDF Vectorization for extracting core textual features.
* **Cosine Similarity Matching:** Efficient similarity metric calculation to find exact or close semantic matches.
* **Confidence Thresholding:** Handles out-of-scope/unmatched queries with fallback responses.
* **Interactive Web Interface:** Streamlined user-friendly UI built using Streamlit.

---

## 🛠️ Tech Stack
* **Language:** Python
* **NLP Library:** NLTK
* **Machine Learning:** Scikit-learn
* **Frontend UI:** Streamlit
